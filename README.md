# Smart PG Finder & Women Safety System

**Status: Front-end concept / UI prototype**

An early-stage concept for helping people explore paying-guest (PG) accommodation, with an emphasis on vacancy information and women's safety.

## What is currently in this repository?

- `index.html` — a static landing page presenting the product concept
- Sections introducing planned PG search, vacancy prediction, occupancy tracking, and safety features
- A sample PG owner registration form (front-end only)

## Planned Features (Not Yet Implemented)

- Location, budget, and room-type search filters
- AI-based vacancy prediction
- IoT-enabled room availability tracking
- Analytics dashboard
- PG owner registration and administrative review
- Women-focused safety features such as SOS alerts and location sharing

> **Important:** The AI, IoT, backend, authentication, and safety services are ideas shown in the interface. They are **not implemented** in this repository. The registration form does not submit to a server.

## How to View

1. Download or clone this repository.
2. Open `index.html` in a web browser.

## Next Steps

Implement real listing data, a backend, validated forms, and the planned features incrementally.
